## 鹈鹕骑单车 3D 游戏（artifacts/pelican-bike/）

- 用户需求：「画个鹈鹕骑单车的 3D 游戏」。目录里已有一版 2D SVG 动画（index.html，21:45 由更早会话生成，带踩踏板 IK 与车铃音效），本次另建真正的 3D 可玩游戏。
- 产物：`artifacts/pelican-bike/pelican-ride-3d.html`（约 650KB 单文件，内联 Three.js r149 UMD + 游戏代码，离线可玩）。
- 源码拆分：part1.html（HTML 外壳/HUD/样式）+ three.min.js + part2.html（script 分隔）+ game.js（游戏逻辑）+ part3.html（收尾）；重新组装命令：`cat part1.html three.min.js part2.html game.js part3.html > pelican-ride-3d.html`。
- 玩法：三车道变道（←/→/A/D）、空格跳跃、吃小鱼 +15 分、岩石/路障/木箱三种障碍、3 颗♥、撞毁翻车动画、localStorage 最高分（key: pelican_best_3d）、WebAudio 合成音效、触屏按钮（pointer:coarse 显示）。
- 技术要点：鹈鹕+单车全程序化建模；踩踏板用两骨骼 IK（ikKnee，膝盖朝前）；车架/脖子用 setFromUnitVectors 对齐圆柱；场景为海岸公路（左草地棕榈/右沙滩大海）、虚线/立柱/景物/云/山按不同视差系数滚动回收；相机跟随 + FOV 随速度拉伸。
- 验证方法：无头 Chrome（`C:\Users\Administrator\AppData\Local\Google\Chrome\Application\chrome.exe`）`--headless=new --no-sandbox --disable-gpu --enable-unsafe-swiftshader --user-data-dir=<临时目录> --virtual-time-budget=N --screenshot=...`；JS 报错用 `--enable-logging=stderr` 抓 CONSOLE 行。软件渲染慢，budget 2500ms 约 1-2 分钟，大 budget 用 run_in_background。
- 踩坑记录：
  1. 组装时漏 cat game.js → 页面无报错但画布全空白（THREE 加载了却没有游戏代码），教训：组装后必须 grep 验证关键函数名存在。
  2. 环境里 rm -rf 新建的临时目录会被 safe-delete  hook 拦截并中断整条命令链；Chrome profile 目录直接用系统 Temp 下新名字，别删。
  3. 初始灯光总量约 2.1 导致画面严重发白，降到 hemi 0.55 + ambient 0.06 + dir 0.85 并加深场景配色后正常。
  4. 被 SIGTERM 中断的 Chrome 会残留并锁住默认 profile，导致后续启动静默失败；用独立 --user-data-dir 可规避。
- 用户偏好延续：结构化总结用表格；技术回复中文。
