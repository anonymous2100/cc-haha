## 0.7.3 重新打包（绕开 WorkBuddy 文件锁）

- 失败链与根因：
  1) 12:15 构建被会话重启中断，遗留半清理的 build-artifacts/electron（大部分文件已删，被 WorkBuddy 索引进程 pid 15396 锁住的 app.asar 残留）。
  2) WorkBuddy.exe（宿主，不可杀）持有 build-artifacts 下多个 asar 句柄 → electron-builder 清理旧目录失败。用 handle.exe（Sysinternals，下载到 TEMP 目录）定位。
  3) bunx electron-builder 的 -c 前缀参数被 bun 吞掉；node cli.js 直调在 PowerShell 5.1 下 -c 与值被拆开；停止解析符（--%）会把 2>&1 也原样传给程序。
  4) --config 指定配置文件是整体覆盖而非合并 → files/nsis/publish 全丢，产物 1.5GB（默认 files 规则打进全部 node_modules）。
- 最终方案：把 desktop/package.json 的 build 配置完整拷贝到 desktop/build-artifacts/eb-full.json（仅 output 改 electron-r3），bunx electron-builder --config build-artifacts/eb-full.json。
- 产物目录：windows-x64-r3（自洽副本）；旧 windows-x64 不可清理（asar 被锁）。
- 教训：electron-builder 的 --config 文件是覆盖不是合并；bunx 会拦截 -c 前缀参数。

## 鹈鹕骑单车网页（纯 SVG 动画页）

- 产物：`artifacts/pelican-bike/index.html`（单文件，无外部依赖）。
- 做法：手写 SVG 场景 + requestAnimationFrame 驱动；两骨骼 IK 解膝盖，让腿始终踩在踏板上；车轮/曲柄/路面虚线/云按角度联动；WebAudio 合成车铃（点击或空格触发，带涟漪动画 + 短暂加速）。
- 无浏览器环境时的视觉验证套路：用 `node_modules/sharp` 把 HTML 里的 `<svg>` 抽出来栅格化成 PNG，再用 Read 看图；再用同一套数学批量生成多个曲柄角度的对照图验证动画不脱节。注意 sharp/librsvg 对 CSS 动画与部分 filter 支持有限（feGaussianBlur 阴影基本不显示）。
- 踩坑：`linearGradient` 默认按 bbox 计算，背景矩形放大后渐变被拉伸到只剩局部颜色 → 改 `gradientUnits="userSpaceOnUse"`。
